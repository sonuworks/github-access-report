# Contributor Guide

Welcome to the GitHub Access Report project.

## Participation

All community participants are expected to be respectful, professional, and collaborative.

## Pull Requests

1. Create a feature branch from `main`.
2. Ensure Java 21 and Maven are installed locally.
3. Include tests covering new functionality or bug fixes.
4. Verify the full test suite passes with:
   `mvn clean test`
5. Submit a pull request targeting `main`. All CI checks and code analysis must pass before merging.

## Reporting Issues

- For general bugs and feature requests, open a GitHub Issue.
- For security issues, refer to the private disclosure policy outlined in SECURITY.md.
